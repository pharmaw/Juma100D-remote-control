# Juma100D-remote-control
How you can remotely control Juma100 and clones via a container in Thetis.
A good knlowledge of Thetis containers and MMIO is advised.
You will need to download and read the .doc file before to use.
There are several versions:
V2 is a complete control for use with F-sense for Thetis v2.10.3.12 beta1 MI0BOT.
V3 add the manual band switch for v2.10.3.12 beta1 MI0BOT.
From Thetis v2.10.3.12 beta2 MI0BOT some controls were updated so a different version is needed,
respectively V2_2 and V3_2. You will find in development section.
